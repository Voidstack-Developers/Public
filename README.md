# Last Extraction | Public Changelog

Welcome to the official public changelog for **Last Extraction**, a free-to-play Roblox game developed by **WarSnacks**, a game studio operating under **Voidstack**.

This repository provides a public record of changes made to the game, including new features, bug fixes, gameplay adjustments, performance improvements, and other updates.

The changelogs primarily cover updates to the release version of Last Extraction, allowing players to stay informed about changes made to the game.

- Other additions, modifications, and removals

## Finding Changes for a Specific Version

Each changelog file is named after its corresponding Git commit hash.

To find the changes associated with the current game version:

1. Open the [current build information](https://github.com/Voidstack-Developers/Public/blob/main/game/buildinfo).
2. Locate the commit hash listed in the file.
3. Open the [changelogs directory](https://github.com/Voidstack-Developers/Public/tree/main/game/changelogs).
4. Find and open the file with the matching commit hash.

This allows you to identify the changes associated with a specific published build.

## About This Repository

This repository exists to make the changes made to Last Extraction accessible to players and the public.

**This is not the game's source code repository.** The actual game source code remains private. Only public-facing information, including changelogs and build information, is provided here.

Making this repository public does not grant access to private source code, internal development files, or unreleased content.
